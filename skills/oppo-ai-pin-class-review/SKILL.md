# 课堂回顾与复习

先读 [共同数据、采集与确认规则](../../references/shared-workflow.md)，按其进行同步、去重、确认和元数据导出。

## 先列出，再选择

1. 读取集中课程台账。首次缺少课程信息时使用本地课程管理建立登记；不要在未关联教材时声称已结合教材。
2. 检查课程索引：没有 last_indexed_at 或距上次成功更新时间 >=72 小时，自动派发指定的 gpt-6-luna/high 子 Agent 更新；不以尝试时间当成功时间。更新失败保留旧索引，说明哪些资料尚未刷新，不将失败写成成功。
3. 每次调用同步两个远程接口，收齐新数据和分页，列出所有新增/变化及尚未处理条目。表格含编号、日期起止/时长、原主题、建议课程、依据、转写/摘要可用性；疑似非课程、噪声、示例、归属不明也列出。对多会话组成一节课提供合并建议。逐句检查 results[].sentences[] 的文字与时间，以及前后相邻段落/会话；摘要结束不等于下课。按共同规则列出转录覆盖范围、缺口和与实际下课时间的差异。
4. 必须在这里等待用户明确选定编号及课程；不能因为模型确信课程归属就跳过。用户本次请求已经明确指定记录和课程时，核对后可视为确认。先确认再总结，避免搞错课程。

## 生成有依据的笔记

**以转录原文为主要总结依据，MCP 自动总结仅作参考。** 必须完整阅读所选记录的转录及前后文，再独立组织笔记；自动摘要、主题和重点只辅助定位，关键内容逐项回查原文。冲突、原文缺失和疑似转录错误按共同证据规则处理，不用摘要冒充教师原话或填补没读过的片段。

读取所选转写及上下文，按索引定位教材、课件和实验指导书，实际打开相关章节。索引只提供位置，不是资料正文。PPTX 同时看幻灯片及讲者备注；PDF 区分 PDF 页码和印刷页码。标题/编号须来自教材；不能编造章节名或页码。

围绕当堂主题形成连贯笔记：概念前提、课堂解释与例子、课件/教材补充、易混处、必要的操作步骤/公式；按材料需要组织，不机械填满固定章节。课堂内容、教材补充、尚待核实清楚区分。只有转写中有证据的通知才作为课堂要求，转述保留转述属性。代码、结论、实验测量结果不得补造。

引用要能就地核对：关键依据附短原文和上下文说明，标明来源文件、章节编号/名称、页码或幻灯片页。笔记中用 `<a href="#source-…">` 跳转到对应引用区，引用区有返回链接；长引文可用模板现有折叠组件。链接本地 PDF 可用相对路径加 `#page=N`；Markdown 的文件/章节跳转仅在目标阅读器支持时提供，不能承诺 HTML 浏览器能直接渲染 Markdown 锚点。无可靠跳转时内嵌必要原文，不能只留页码让用户反复寻找。记录原句附本地时区日期、起止时间、说话人编号，绝不伪造播放按钮。长段教材解释主要用自己的话，保留必要引用。

## 可选生成技能与文件命名

用户可以指定自己的 HTML 笔记技能和插画技能，按其选择执行，不锁定 whisper 系列。用户未指定时，按下面顺序自动选择；不要求安装可选技能，不因缺失而停下。

1. 用户指定的技能可用：读取并采用该技能，保留本工作流的课程确认、来源引用、文件命名与离线交付要求。用户指定的技能不存在时说明后自动降级，不虚构已调用。
2. whisper-html 与 whisper-illustration 都可用：读取当前技能并采用文档型模板及主题插画流程，复用其真实生成器和外壳。
3. whisper-html 缺失：由 Agent 自主设计、编写自包含 HTML 课程笔记。至少包含清晰目录、章节层级、必要公式或代码、来源摘录与内部引用跳转、移动端布局；不模仿或宣称用了不存在的模板。
4. whisper-illustration 缺失、无生图能力，或现有 HTML 技能强制要求的插画依赖不可用：省略装饰插画，或使用简单原创 SVG/HTML 概念图；若不能满足 whisper-html 的强制依赖，整体转为无技能 HTML 路径，不修改外部技能规则来假称遵守。准确流程、公式和数据仍由可靠代码绘制，不拿图标冒充主题插画，不擅自复刻个人 IP。

说明实际采用的技能或自主生成方式，放在交付说明而非课堂正文。降级只改变制作方式，不降低材料核对与课程内容质量。所有路径都检查目录、引用链接、离线资源及手机阅读。

输出可离线打开的 HTML，自包含资源，不依赖插件缓存和临时路径。文件名 `YYYYMMDD-课程名-章节编号 摘要主题.html`，日期是课堂发生日（本地时区），不是生成日：

- 单章节：`20261016-操作系统原理-1.2 操作系统的分类.html`
- 多章节：`20261016-操作系统原理-1.2&1.3 操作系统的分类及发展.html`

多个章节编号用 `&` 连接，后面写合并后的主题总结；不要写成“1.2 完整章名+1.3 完整章名-再次概括”。没有可靠章节编号时用课堂主题，不捏造编号。清理 Windows 非法字符；同名内容保留版本后缀，不覆盖旧笔记。路径过长缩短主题，完整标题保留在正文与来源清单。

每门课程 `<root>/OPPO-AI-Pin/元数据/` 保存所选记录副本、来源清单（资料路径/章节/页码、记录hash、时间范围）以及生成内容源码/配置（采用 whisper-html 时保存其内容 JSON）；生成 HTML 放 `<root>/OPPO-AI-Pin/课堂笔记/`。检查代表性桌面、手机、目录、引用跳转和离线资源后，才标记完成并交付文件链接。生成笔记不代表完成作业，也不自动写入飞书。


完成后调用 `app.py --data-root <目录> notes --course-id <ID>` 验证新笔记已出现在列表中，并返回该课程 `open --course-id <ID> --view notes` 的完整可点击入口。来源清单与笔记正文写清摘要区间、实际采纳的原句区间、未覆盖范围；不因设备把课堂拆成几段就漏掉后面的内容。尚待用户选择时也须提供课程入口。
